# FORESIGHT HUB — UI/UX + Content Enhancement

## Goal
Turn the site into a stronger **personal brand** for Ali Mansouri that speaks to three audiences — **CEOs/executives, entrepreneurs, and PhD students/researchers** — with sharper copy, audience-targeted paths, an authoritative methodology digest, and a more polished, credible visual rhythm. All changes **bilingual FA + EN**.

## How the site works (key constraint)
- Live pages load `locales/{fa,en}.json`. Source of truth = `js/locales/{fa,en}/*.js`.
- **Edit JS locale files → run `npm run locales` → regenerates JSON → bump `SFH_LOCALE_VERSION`.**
- Content is rendered from `data-i18n="key.path"` attributes; arrays render via functions in `js/core/i18n-render.js`.
- Home styling lives in `css/academic-platform.css` (not style.css).
